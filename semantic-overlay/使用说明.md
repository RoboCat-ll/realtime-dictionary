# 实时字典使用说明

当前版本：**0.20.3-beta**。主流程支持 Windows 微信、QQ 的单条消息解释；会议、整窗扫描和浏览器适配保留为实验功能。

## 启动与配置

安装版双击桌面“实时字典”；便携版完整解压后，运行 `native-host/bin/SemanticOverlay.exe`。托盘图标出现后即可使用，没有主窗口。日常快捷方式直接启动图形程序，不会先弹命令行。开发时用 `start.cmd` 检查源码、编译和启动，这个入口可能显示命令行。

右键托盘 → **模型设置**，选择自己已授权的服务商和型号，测试连接后保存。新密钥以 Windows 当前用户加密方式保存，不放进分发包。硅基流动只允许核实免费的型号，其全部 DeepSeek 和其他收费型号均禁用。官方 DeepSeek 等收费服务的费用由对应账号承担；不会自动切换收费兜底。

## 解释消息与查词

1. 在微信或 QQ 中按 **Ctrl+Alt+K**，出现待选提示。
2. 在 **10 秒内点击一次目标消息**。无需先复制全文，也无需按住快捷键。普通未进入待选状态的点击不会触发请求。
3. 先看到整条消息的意思，再看到可点击的术语。程序优先读取完整消息控件；读不到时对整个气泡做本地 OCR。
4. 点击蓝色术语查看语境解释；没标出的词也能拖选，点击附近的 **解释** 按钮，或按 **Ctrl+Enter**。
5. **展开解释** 才会请求详细内容；本卡片内再次展开复用已有内容，不重复请求。首次解释失败时可点 **重试解释**。

消息卡片默认只展开整句含义和原句。术语直接在原句里点击，不再重复列成一排按钮；选词或点击后才展开注释，没有日程候选时不保留空日程区域。纠错编辑仍可按需展开。

也可选中文字后按 **Ctrl+Alt+D** 主动查词。当前软件无法提供选区时，在查词窗口输入或粘贴词语即可。词语最多 200 字符，消息最多 1000 字符；超长内容不会静默裁剪后发送。

等待状态显示已等待秒数。识别有误时点击 **识别有误？展开并修改原文**；修改会丢弃旧请求结果，点击 **确认并解释** 提交新内容。查词途中换词也不会被上一词的迟到结果覆盖。失败提示区分超时、连接、认证和运行文件缺失，不展示服务商内部错误正文。

## 识别与标注保护

OCR 修复不会把完整的 `GitHub` 和后面的 `is` 拼成一个词，也不会猜改短英文词、编号、链接、邮箱和文件路径。拆分的 `one a pi`、`b。。tcamp` 仍可修复。模型校正不能新增或删除否定、取消、改期等表达；不确定时保留可编辑的原句。

完整概念会优先于只出现在其内部的短词。例如仅出现“卷积神经网络”时，不再重复标出其中的“神经网络”；如果后文单独讨论“神经网络”，仍保留该词。模型已有语境释义不会被通用定义覆盖；缺失释义时可复用已知、同语境的本地定义。未标出的词仍可主动选取解释。

## 日程候选

消息含真实工作安排时，下方出现 **工作与日程 · 待确认**。点击 **添加日程**，本地自动解析并预填完整开始日期；没写年份的月日取下一次到来的日期，今天仍按今年。明确的年份及“去年/明年”等表达优先；历史回顾不自动顺延成未来安排。窗口显示推断依据，今天已过的时间会提示核对，日期始终可修改。核对事项、补齐仍缺失的结束时间/时区及提醒提前量后，再明确确认创建本地提醒。举例、假设或取消安排不应自动创建日程。提醒要求程序保持运行；不是自动写入系统或公司日历。

已识别的信息集中显示为摘要，默认只展开缺失字段；点击 **修改已识别信息** 可调整全部内容。缺少结束时间时，可以明确选择持续 **30 分钟、1 小时或 2 小时**，程序根据开始时间计算结束时间，也可手动填写。不选择时长就不自动假定。信息齐全后，补充输入区域收起；创建仍需点击确认。

## 托盘菜单

- **解释一条消息 / 主动查词**：日常入口。
- **字幕记录**：按日期回看历史，实验开关关闭时也能使用。
- **模型设置**：配置解释服务。
- **设置**：今日模型用量、隐私与密钥状态、字幕保存、熟悉词管理和本地体验数据。
- **实验功能**：会议音源与字幕、整窗扫描、显示方式/密度/范围和浏览器适配。
- **使用帮助 / 退出**：打开说明，或退出本程序及其自有后端。

## 会议字幕（实验）

托盘 **实验功能 → 启用冻结实验功能**，再选择 **工作模式 → 会议语音字幕**。选择音源后切回会议或视频窗口，按 Ctrl+Alt+K 启动；Ctrl+Alt+G 停止。声音只来自系统播放，不录麦克风。进程优先只尝试该窗口所属进程树；不兼容时明确提示全系统音源。

字幕框可移动、缩放，支持打开记录；不自动逐句翻译。记录可按需翻译整段或解释所选词。开启本机保存时按实际日期自动归档，退出后仍能回看；在 **设置 → 将字幕按日期保存在本机** 可关闭后续保存，在记录窗口确认后可删除选定日期的历史。语音服务不可用时会提示，不能以已有视频字幕冒充本程序转录结果。

字幕历史默认不显示空解释区，主动查词或翻译后才展开。切换录制日期或“本次字幕”会清除旧查询，旧请求的迟到结果不会混入新的记录。新字幕追加保留当前阅读位置和选词；窄窗口的日期导航与操作按钮自动换行。

## 隐私与已知边界

模型只收到主动提交的消息、词语及必要上下文；日志不保存正文或密钥。不同服务商需重新确认发送许可。字幕归档是另一项可关闭的本地保存设置。

OCR 有可能错字，第三方客户端可能不提供完整无障碍文字；请核对原句。网络故障和服务排队仍可能导致失败。会议、多显示器和公司职工试用没有因此被认定通过。遇到连续错误，先查看托盘状态和模型设置，再重试；不要反复提交保密信息。
