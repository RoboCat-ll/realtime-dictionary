# Demonstration media

`feature-tour.gif` and `feature-tour.mp4`: current native UI with synthetic
messages, stubbed model answers and subtitle entries. No private chat, audio or
credentials. These are edited feature walkthroughs, not live OCR, transcription,
latency or accuracy evidence. Calendar demonstration stops before creation.
Experimental captions are explicitly labeled. Scenes cover sentence explanation,
term lookup, unmarked selection, expanded detail, calendar confirmation, subtitle
history and explicit translation. No claim that every settings dialog is shown.

Existing `chat-lookup.gif`, `chat-schedule.gif`, `meeting-captions.gif` are older
recordings; their visual styling can differ from the current build. Read README
captions before treating them as evidence. Only reviewed public media belong
here; temporary capture frames stay in ignored `native-host/bin/`.
