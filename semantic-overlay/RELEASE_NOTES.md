# 0.20.4-beta · 2026-10-09

本次同步是开发中的源码快照，不是企业部署认证。

## 用户可见变化

- 消息解释与选词在同一个浮框中切换；支持未高亮词主动查询。
- 同一消息中已成功解释的词可在当前浮框复用；改原文或打开新消息会失效。
- 失败重试保留已有成功结果；迟到响应不覆盖新输入。
- 浮框四边可独立调整；短解释不填满巨大空白；窗口缩放保留阅读内容，滚轮后标明原消息。
- 重复启动通知已有实例，找回已有解释窗口或显示操作说明。
- OCR 校正增加人物、否定、日期、数字及时段保护。
- 日程按北京时间预填，确认前不创建提醒；字幕保留为实验能力，支持历史与按需翻译。
- 安装器校验不再要求已退休的浏览器扩展，缺运行依赖或版本不符仍拒绝。

## 验证与演示

本次重新运行隔离离线测试：252/252 通过。原生诊断采用合成数据；
既往真实客户端检查范围见 REAL_WORLD_TEST_PROTOCOL.md，不能换算总体准确率。
演示使用当前原生界面和预设数据，不调用模型、不采集会议音频、不保存真实提醒。

## 尚未解决的事项

- 原文校正被拒绝后，模型解释仍可能包含同样的不当推断；不能把原文保护等同于释义事实核验。
- 响应头超时重试的费用/延迟收益尚缺代表性对照；关闭窗口不保证服务商停止计费。
- 查词与选句请求尚未统一合并在途重复工作，本地缓存覆盖仍有限。
- 安装更新仍逐文件覆盖，尚无完整事务回滚；旧后台可能需要显式退出。
- 键盘滚动、拖动滚动条等跟随边界仍存在，客户端版本变化可能影响取句。
- 字幕准确率、持续性、异机独立安装及长期故障率未达到可宣称成熟的证据要求。

源码不包含个人配置、API 密钥、日志、聊天截图或本地 Python 运行时。
安装包构建见 DISTRIBUTION.md；仓库未自动发布二进制 Release。
